本章为空间部署后的现场验收安排。除部署方法与判据（来自标定 SOP 与验收记录表，属设计内容）外，\textbf{全部结果待现场执行后填写}，当前一律以红色占位标注，不预设任何数值。

\section{部署点位}

部署遵循标定 SOP：每个监测点 1 块 TX，TX 与 RX 分居活动区两侧、链路中点覆盖活动区；天线竖直同极化；离地 $\ge$1~m、离墙与金属大反射体 $\ge$0.5~m；胶带标记位置并拍照存档。路由器 2.4~GHz 信道手动固定、20~MHz 带宽、关闭自动信道与频段合一。
