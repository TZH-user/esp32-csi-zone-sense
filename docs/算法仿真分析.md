# CIS 检测算法 Python 仿真分析（黄金模型）

> 复现方式：`cd F:\ESP\projects\ESP32-CIS\sim && python run_scenarios.py`（约 2~4 分钟；
> `--quick` 减少重复组数）。种子固定，结果可复现。原始数据表：`sim/out/results.md`，
> 图 5 张：`sim/out/s*.png`。本文引用的数字全部来自 2026-10-28 full 模式运行。

## 1. 定位：仿真验证什么、不验证什么

固件检测算法已在实机通过 M1~M4 验证，本仿真**不替代实机验收**，用途有三：

1. **参数裕量预检**——在你去现场前量化阈值裕量、滞回窗口在正常/降级条件下
   能否满足 M5 判据，避免到场才发现某判据贴线；
2. **降级行为地图**——拥塞丢窗、近场饱和、训练污染、RSSI 突变四类现场最可能
   遇到的情况，各会劣化到什么程度、判据口径怎么放宽；
3. **报告素材**——算法章节的时序图/扫描曲线（报告任务书 fact 库原本缺这部分）。

不覆盖：多 peer 空口串扰（M4 已用"复位注入+MAC 归属"实测隔离，见 §6）、
UDP/串口链路层、真实多径空间结构。

## 2. 方法

### 2.1 黄金模型 = cis_detect.c 逐行忠实移植（sim/detect_model.py）

不是" reimplement 一个类似算法"，而是把固件语义逐条镜像，包括容易忽略的细节：

| 固件语义（cis_detect.c） | 移植处理 |
|---|---|
| `(uint32)(e2 - mean²)` 整数截断（:233） | Python `& 0xFFFFFFFF` 镜像 |
| 整除取均值/方差 + centi 换算（:231-272） | 全程整数 `//`，含下偏置 |
| RSSI 突变：丢包+整窗 dirty，但 `rssi_prev` 每包更新（:184-205） | 持续型 RSSI 台阶只污染第一窗 |
| 空窗/脏窗：不产特征、不进 FSM、不累计 quiet，`last_ts_ms` 照刷（:259-267） | 同 |
| FSM 比较用未钳制 var_c，事件 score 才 clamp（:313, :124） | 同 |
| quiet_ms 只在非超阈且非 IDLE 窗累计；迁移时清零（:322, :121） | 同 |
| 训练期照发特征但不做判决；阈值 = noise×margin//100，下限 15c（:282-308） | 同 |

### 2.2 包级信道模型与标定锚点（sim/signal_gen.py）

| 参数 | 值 | 依据 |
|---|---|---|
| 静息幅值均值 | 13.0 raw（=1300c） | M4 peer list 实测 mean=1307c |
| 静息噪声 std | 1.75 raw | NVS 阈值 681c=3×noise → noise≈227c（模型含整除下偏，实测模型静息 210c） |
| 幅值硬上限 | 180 raw | int8 I/Q 单载波 √2×127；M4 异常 mean=1700c=170 raw 已贴近 |
| 走动信号 | OU 慢衰落，τ=0.08s，σ_m=2k·σn（k=5） | 见下"探针标定" |
| 每窗包数 | Poisson(4) | esp-radar csi_handle_window≈40ms @ recv 10ms |
| 窗周期 | 0.1s（10Hz） | CONFIG_CIS_FEATURE_RATE_HZ=10，M1 实测 9.1Hz |

**关键建模决定**：走动必须建成时间相关慢衰落，不能用 i.i.d. 噪声。i.i.d. 模型下
相邻窗独立，"连续 N=10 窗超阈"的概率是单窗的 10 次方，检出率会归零——与实机
M2/M4"走动可靠触发"矛盾。OU 过程（τ=0.08s）模拟人移动时多径图样连续演化，
探针标定后模型同时命中三个实测锚点：**静息 210c（锚 227c）、检出 10/10、
MOTION 时延 1.75s、STILL 2.97s**（S0 表）。

## 3. 结果与解读

### S0 标定核对

静息 var_c=210c（锚点 227c）、mean=1298c（锚 1307c）；10s 清场训练 noise=244c
→ 阈值 732c；走动 var=6806c≈静息×32，对阈值超阈率 85%。模型分布与台架同量级。

### S1 阈值裕量扫描（sim/out/s1_margin.png）

| margin | 误报/10min | 走动检出 | MOTION 时延 | STILL 时延 |
|---|---|---|---|---|
| 200% | 0.0 | 8/10 | 1.95s | **19.26s** |
| 250% | 0.0 | 10/10 | 2.13s | 5.24s |
| 300% | 0.0 | 9/10 | 2.28s | 3.04s |
| 350~500% | 0.0 | 9/10 | 2.32~2.77s | 2.37~2.38s |

三个结论：
- **误报对裕量完全不敏感（全部 0）**。静息方差估计量虽是 χ²(3) 厚尾（P95=568c，
  偶见 >1000c 单窗），但"连续 10 窗超阈"把它全部挡住（10min 最长连续超阈段=1 窗）。
- **裕量下限由 STILL 判据决定，不是误报**。200% 时（阈≈488c）P(静息单窗超阈)≈19%，
  "连续 25 窗低于阈值"被频繁打断，停走确认被饿到平均 19s——远超 3s 判据。
- **裕量上限由检出率决定**：500% 时仍 9/10，但时延开始变大。**300% 默认值处于
  合理窗 [250%, 500%] 的中段，不改**；现场 ±10~20% 微调（指南 §4）是安全的。

### S2 拥塞丢窗扫描（sim/out/s2_rate.png）

| 丢窗 p | 有效率 | 走动检出 | STILL 时延 | 挥手3s |
|---|---|---|---|---|
| 0 | 10Hz | 8/10 | 2.93s | ✓ |
| 0.3 | 6.9Hz | 9/10 | **4.19s** | ✓ |
| 0.5 | 5.0Hz | 8/10 | 10.2s | ✗ |
| 0.7 | 3.2Hz | 4/10 | 9.0s | ✗ |
| 0.85 | 1.5Hz | 2/10 | 39.4s | ✗ |

机理：空窗不进 FSM（固件语义），M=25 个**有效窗**才判 STILL——STILL 时延≈25/有效率，
拥塞最先杀死的就是"停走 3s"判据（有效率 7Hz 已 4.2s）。检出率相对耐拥塞（时域
相关帮它攒连续超阈窗）。**对策已写进验收指南 §3.3**：UI 实时特征率 ≥9Hz 按 3s 判，
更低按 25/率+1s 放宽；挥手用例在有效率 <8Hz 时改长动作。

### S3 RSSI 突变过滤（|Δ|>6dB）

突变率 0→1 次/s（脏窗率 0→15%）：走动检出全部 10/10，时延无恶化。过滤的代价
只是特征率等比下降（脏窗无特征），联动 S2 结论。**盲区**：无 RSSI 伴随的幅值台阶
（挪天线后未恢复、遮挡突变）×1.6 步进 5 组全部 0 误报——方差检测对"均值台阶"免疫
（整窗同步平移不产生窗内方差），单窗尖峰也被 N=10 挡住。但台阶会使已训阈值失配，
**挪动后必须重训**（SOP 既有规定，此处是机理解释）。

### S4 近场饱和（sim/out/s4_saturation.png）

| 静息 mean_c | 走/静 var 比 | 走动检出 |
|---|---|---|
| 130~1200 | 41~55× | 8/8 |
| 1500 | 27× | 4/8 |
| **1720** | **5.8×** | **0/8** |

幅值贴近 int8 上限被削顶，走动只能把幅值往下打，窗内方差塌缩。**1720c 处模型
走动 var=1364c，与 M4 异常实测（mean≈1700c、var=1224c）几乎一致**——M4 期间
RX 两次重启 + 链路劣化的"近场饱和"假设得到定量支持。红线：**UI 看 mean_c>1500
立即拉远 TX**（1200c 以内无影响）。

### S5 训练污染（sim/out/s5_contamination.png）

| 污染 | 阈值 | 走动检出 |
|---|---|---|
| 0s（干净） | 687c（×1.01 基线） | 10/10 |
| **2s** | 4282c（×6.29） | **0/10** |
| 5~15s | 9768~26610c | 0/10 |

15s 训练里最后 2 秒有人走动，阈值虚高 6 倍，检出全灭。**清场是硬要求**，不是
"尽量"。重训判定规则：train 完成时看 noise，远链路基线 ≈220c（近链路 ≈6800c，
TX2 实测 20367/3），**noise > 2×基线就重训**（0x30 帧和 UI 标定回填都会显示 noise）。

### S6 时序健全性（sim/out/s6_timeline.png）

训练→静置→走 10s→停 40s→挥手 3s→静置 20s 全序列事件正确：未标定期 0.9s 即
MOTION（默认阈值 30c < 噪声底 ~210c，**上电未标定必误报，预期行为**——与 M4
实机日志 `thr=0 state=1` 一致）；标定后走动时延 2.80s、STILL 2.50s、挥手可检、
每段活动结束 10s hold 后回落 IDLE。

## 4. 调整建议汇总（按优先级）

| # | 建议 | 依据 | 落到哪 |
|---|---|---|---|
| 1 | margin 保持 300%；现场微调下限别低于 250% | S1：200% 时 STILL 饿死 19s | 指南 §4 微调注记 |
| 2 | 验收先看 UI 特征率：≥9Hz 按 3s 判 STILL，更低按 25/率+1s 放宽 | S2 | 指南 §3.3 拥塞行（已写入） |
| 3 | mean_c>1500 立即拉远 TX（1200 内无影响） | S4 复现 M4 异常 | 指南 §3.3 近场行（已写入） |
| 4 | 清场 train；noise>2×基线（远链 ~220c）就重训 | S5：2s 污染→检出全灭 | 指南 §4/标定SOP |
| 5 | 挪动天线/TX 后必须重训（幅值台阶不误报但破坏阈值） | S3 盲区测试 | SOP 既有规定，机理补充 |
| 6 | 单次走动有 ~10% 漏检（深衰落期方差塌缩），M5 用 ≥9/10 统计判据是对的 | S1 漏检 burst 剖析 | 验收记录表口径 |
| 7 | 固件不改。可选改进（记录不实施）：M 按有效窗率自适应；train 完成 noise 超 2×EMA 基线时告警 | S2/S5 | 本文档存档 |

## 5. 与实机证据的一致性核对

| 量 | 实测 | 模型 |
|---|---|---|
| 静息噪声底（远链） | 227c（681÷3） | 210~244c |
| 静息幅值均值 | 1307c | 1298c |
| 干净训练阈值 | 681c | 687~732c |
| 近链噪声底 | 6789c（20367÷3） | S4 未复现该 AGC 档位（模型单档），量级逻辑一致 |
| M4 异常形态 | mean 1700c / var 1224c | mean 1720c / 走动 var 1364c，检出 0/8 |
| 停走 STILL | M2 实测 ≤3s | 2.4~2.9s（10Hz、margin≥250%） |
| 未标定期行为 | thr=0 时 state=1（M4 日志） | 0.9s 即 MOTION |

## 6. 局限（报告里照实写）

1. 走动信号模型（k、τ、σ_m）为假设参数，只锚定了宏观统计（检出率/时延/噪声底），
   未做真实信道 impulse response 级建模；
2. 单 peer 单链路建模；多 peer 串扰未仿真（M4 已实机验证 MAC 分发隔离）；
3. 未覆盖 UDP/串口传输层与上位机（M2/M3 已实机验证）；
4. RSSI 突变模型为台阶+保持，真实 AGC 行为可能更复杂；
5. 黄金模型镜像的是 cis_detect.c 当前版本，固件算法若改动需重新对齐（文件头有语义清单）。
